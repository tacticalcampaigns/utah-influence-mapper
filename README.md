# Utah Influence Mapper — generated site

Static daily snapshots of the Utah Influence Mapper, served at
`/utah-influence-mapper/` on the Tactical data hub.

This repository holds generated files only: HTML pages, the
Tactical Campaigns logo, and this README. It is regenerated by the
pipeline every day from the latest scored data — do not edit the
pages here; they are overwritten on the next run.

How the scores are built, what sources are used, and what is
missing (including the X gap) is documented on the site's
methodology page: `/utah-influence-mapper/methodology.html`.
